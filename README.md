# Plantilla Base: Taller de Colecciones Polimórficas, Casting e `instanceof`

Proyecto inicial para el trabajo práctico en IDE (**Sesión 12 • POO**).

## Instrucciones
1. Abre `src/ProcesadorPagos.java` y completa los tres bloques `TODO`.
2. Compila y ejecuta `Main.java` para comprobar que las comisiones, los totales y los datos específicos de cada subclase se procesan sin errores de casting.

## Compilación y Ejecución
```bash
javac -encoding utf-8 -d bin src/*.java
java -cp bin Main
```
